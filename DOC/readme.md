# AI Diet Menu Planner

AI Diet Menu Planner 是一个运行在 Mac mini 上的本地 AI 助手。

它每天自动根据用户家中已有的食材，生成一天的减脂菜单，并提供详细的烹饪步骤。

本项目专注于一件事情：

> 帮助用户每天决定"今天吃什么"，并尽可能利用现有食材。

项目使用 Google Gemini API 生成菜单，不依赖复杂的营养计算，也不需要维护大量数据。

---

## 功能

### 每日菜单

每天自动生成：

- 早餐
- 午餐
- 晚餐

每餐包含：

- 食材
- 用量
- 烹饪步骤

---

### 食材管理

维护当前拥有的食材。

例如：

- 鸡胸肉
- 鸡腿肉
- 鸡蛋
- 牛奶
- 燕麦
- 土豆
- 黄瓜
- 生菜
- 甜椒

只记录：

> 是否拥有该食材。

不记录：

- 数量
- 重量
- 营养成分

---

### 菜单历史

保存最近几天菜单。

AI 会尽量避免连续重复相同料理。

---

### 购物建议

如果菜单需要某些食材，而用户当前没有，

AI 会自动加入：

> 建议购买

例如：

- 三文鱼
- 西兰花
- 希腊酸奶

---

## 技术

- Python
- Google Gemini API
- FastAPI
- SQLite
- Jinja2

全部运行于本地。

---

## 项目目标

本项目不是：

- 减肥计划软件
- 卡路里计算器
- 营养分析工具

本项目只负责：

> 每天提供简单、健康、容易执行的减脂菜单。
